Pencapaian produksi terhadap BBC dan Target

Produksi = ton TBS aktual (ESTATE_COST). BBC = forecast sensus (Snowflake YTD_TON_BBC Jan–Jun, file SAP Jul–Sep). Target = budget produksi per blok dari file perencanaan 2026, didistribusi per bulan sesuai kolom DISTRIBUSI. Ach = produksi ÷ BBC atau ÷ Target; titik hijau ≥ 100%.

Pencapaian cost (Rp/Kg)

EC Rp/Kg = total biaya ÷ ton produksi (tujuh komponen: Rawat, Infra, Pupuk, Panen, Transport, Umum, Penyusutan). Budget Rp/Kg = budget biaya ÷ Target produksi. Ach cost = aktual ÷ budget; di bawah 100% berarti lebih hemat (titik hijau). Sumber: PRS_COST.ESTATE_COST; PMY = afd A + C.
